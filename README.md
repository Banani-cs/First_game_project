# First_game_project

A Muck-inspired concept and my first project learning C# and Unity. I gave myself 5 days of holiday to see how far I could get, and it turned into a 2-month game idea (with a 3-week pause for midterms in the middle).

## How to play

Go up to the rabbits, "kill" 10 of them, and you win!!!!

**Controls:** 

- AWSD to move
- Just walk near the "enemies"(rabbits) to kill
- Press `I` for inventory
- Click retry after winning to retry

## What's in it

- Player movement
- Enemies that spawn and die (they get deleted)
- A working inventory (hotkey `I`)
- A map
- A retry feature

The inventory doesn't serve any purpose in the game. I tried to build something around it, then realized it wasn't the direction I wanted the game to go. It was too late to stop, so I finished it anyway.

## How to open it

- Download the `.zip` from the releases, then extract it, then run the `.exe`

Unity Hub option:

1. Clone or download this repo.
2. Install Unity Hub, then install Unity 6.6.
3. In Unity Hub, click Add > Add project from disk, and select the project folder (the one that contains `Assets`).
4. Open the scene SampleScene and press Play.

The first open can take a few minutes while Unity rebuilds its cache. That's normal.

## What I learned

- Keeping the scope narrow, finishing something I committed to, and building what I enjoy instead of what other people expect from me
